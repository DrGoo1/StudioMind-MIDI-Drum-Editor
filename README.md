# StudioMind MIDI Drum Editor

Independent macOS beta 0.2.17 for Universal Audio LUNA. Edit drum MIDI in a dedicated grid with independent note scrolling, exact Nudge, selected-hit Quantize with Strength and Swing, and Velocity and CC lanes.

Tested on Apple silicon with LUNA 3.1.2 (build 4693). Windows and broader kit mappings are unverified.

Download the .lunaaddon release asset and open it in LUNA. In the Timeline, select an instrument MIDI clip and choose Add Ons > Editors > StudioMind MIDI Drum Editor. Start with a copy of a session. See the PDF user guide for details.

StudioMind MIDI Drum Editor is an independent add-on and not an official Universal Audio release.

See the [0.2.17 User Guide](USER-GUIDE.md) for setup, editing, Undo, and troubleshooting.
